# XR-Project: Psychological Experiment Rooms

Final project for *Fundamentals of eXtended Reality* (Master HCI, Université Paris-Saclay).

The participant moves through a series of rooms. Each room has a **boring main task** that has to be completed to unlock the door to the next room, and the room is full of **fun distractions** (a playable piano, slot machines...). The idea is to observe how a participant handles an annoying, repetitive task when more entertaining things are within reach.

- **First-person navigation** with keyboard and mouse (WASD to walk, mouse to look)
- **Ray cast interaction**: the player aims with the crosshair and left-clicks objects within reach (3 m): buttons, screens, doors, piano keys, slot machines
- **Two main tasks**, each unlocking the next door:
  - **Colour task (Room 1)**: a 10×10 grid of red, green and blue cells is shown on a monitor. The player presses the button of the colour that appears the most. The difference between colours is small, so it requires attention. 5 correct answers in a row are needed, and a wrong answer resets the progress.
  - **Captcha task (Room 2)**: the player clicks the monitor to start typing. It shows either distorted characters to copy (random rotation, offset and size of each character), or a 3×3 grid of images where the player types the numbers of every image containing a given object. Again, 5 correct answers in a row are needed.
- **Progress**: boxes fill up on the screen with each correct answer in a row
- **Distractions**:
  - **Piano**: each of the 52 white keys plays its own note and moves down when pressed. The notes are generated by code, so no audio file is needed for them.
  - **Slot machines**: they spin on their own from time to time, and the player can also spin them by clicking.
