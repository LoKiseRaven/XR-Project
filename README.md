# XR-Project: Psychological Experiment Rooms

Final project for *Fundamentals of eXtended Reality* (Master HCI, Université Paris-Saclay).

The participant moves through a series of rooms. Each room has a **boring main task** that has to be completed to unlock the door to the next room, and the room is full of **fun distractions** (a playable piano, slot machines...). The idea is to observe how a participant handles an annoying, repetitive task when more entertaining things are within reach.

## What has been implemented

| Concept | Implementation(s) |
|---|---|
| Manipulation with ray casting at an offset distance or a virtual hand for close-up manipulation | - `PlayerInteraction` casts a ray from the camera (3 m reach), aimed with the crosshair<br> - Left click on what the ray hits: buttons, screens, doors, piano keys, slot machines<br> - Throwable objects are picked up through the ray, then float at a hold point in front of the camera and can be dropped (E) or thrown (hold and release left click) |
| Activation / Deactivation of objects during runtime | - The door blocker is disabled when the room's task is completed<br> - The feedback light of each monitor is switched on and off after each answer<br> - The captcha screen switches between its panels (text captcha, image captcha) |
| Canvas + 3D TextMeshPro | - World space canvas on the monitors, with TextMeshPro for the instructions, the captcha characters, the typed answer and the completion message<br> - Screen space canvas for the HUD (crosshair and timer)<br> - 3D TextMeshPro for the floating instructions in the start room: goal of the game, controls |
| Physics | - Throwable objects have a Rigidbody with gravity, continuous collision detection, a bounciness and a friction<br> - While held, the object follows the player camera's movements and is dropped if it gets stuck behind a wall<br> - The throw gives the object a velocity (depending on the charge)<br> - Darts stick on collision<br> - The hoop detects basketballs
| Lighting controlled during the interaction | - Each monitor has a feedback light that turns on for 0.3 s after each answer: green for a good answer, red for a wrong one |
| 3D audio integrated in the scene | - The piano notes are played by a spatialised AudioSource on the piano<br> - The slot machines play a sound when they win with an AudioSource placed directly in the machines |
| Timer that counts down the time | - Timer on the HUD (`HudTimer`), kept in a static field so it doesn't reset when changing scene |
| Scripting of object behaviours and logics in the scene | - `ColorScreen` and `CaptchaScreen`: generation of the tasks, answer checking, progress, completion event<br> - `Interactable` and `PlayerInteraction`: buttons with a press animation, clickable screens and doors<br> - `Piano`: key detection, key animation<br> - `Door`, `SpawnPoint`, `SceneTransition` and `PlayerSpawner`: scene transitions, the player appears in front of the right door<br> - `PlayerController`: first-person movement<br> - `HudTimer`: timer kept across scenes |

- **First-person navigation** with keyboard and mouse (WASD to walk, mouse to look)
- **Two main tasks**, each unlocking the next door:
  - **Colour task (Room 1)**: a 10×10 grid of red, green and blue cells is shown on a monitor. The player presses the button of the colour that appears the most. The difference between colours is small, so it requires attention. 5 correct answers in a row are needed, and a wrong answer resets the progress.
  - **Captcha task (Room 2)**: the player clicks the monitor to start typing. It shows either distorted characters to copy (random rotation, offset and size of each character), or a 3×3 grid of images where the player types the numbers of every image containing a given object. Again, 5 correct answers in a row are needed.
- **Progress**: boxes fill up on the screen with each correct answer in a row
- **Distractions**:
  - **Piano**: each of the 52 white keys plays its own note and moves down when pressed. The notes are generated by code, so no audio file is needed for them.
  - **Slot machines**: they spin on their own from time to time, and the player can also spin them by clicking.

## Controls

| Input | Action |
|---|---|
| WASD / ZQSD /  arrows | Walk |
| Mouse | Look around |
| Left click | Interact with what the crosshair points at / pick up an object |
| E | Pick up / drop an object |
| Hold and release left click (holding an object) | Throw it, the longer the hold the stronger the throw |
| Keyboard, Enter | Type and validate a captcha |
| Esc | Leave the captcha screen / free the cursor |
